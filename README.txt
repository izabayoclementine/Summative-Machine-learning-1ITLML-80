
How the System Works

1.User Input
A healthcare worker enters patient details such as age, blood pressure, cholesterol, and test results into a web form.

2.Data Processing
The system automatically cleans and transforms the input data. Missing values are filled, and all values are scaled and encoded to match the format used during model training.

3.Model Prediction
The processed data is sent to the trained machine learning model, which analyzes the pattern of features and predicts the heart disease risk category.

4.Result Display
The predicted risk level is shown on the screen, helping the clinician decide whether the patient needs immediate attention or routine care.
